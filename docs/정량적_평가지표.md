## 상세 정의

### 1. 3D 데이터 표출 응답시간 — 목표: 3초 이내

**정의:** 사용자가 레이어를 활성화하거나 시간대를 변경한 시점부터 해당 데이터가 3D 화면에 완전히 렌더링되어 표출되기까지의 소요시간.

**측정 방법:**
- 브라우저 개발자 도구(Performance 탭) 기반 렌더링 완료 시점 측정
- 수심 지형, 해류 벡터, 선박 위치 등 주요 레이어별 각각 측정
- 10회 반복 측정 후 평균값 산출

**달성 근거:**
- 현재 프로토타입 기준, 지형 메시(51만 정점) 렌더링 약 1.5초
- Three.js BufferGeometry 기반으로 GPU 직접 렌더링하여 고속 처리
- 레이어 토글은 `visible` 속성 전환으로 즉시 반응 (0.01초 미만)

---

### 2. 해양정보 통합 표출 레이어 수 — 목표: 8개 이상

**정의:** 시스템에서 독립적으로 켜고 끌 수 있는 해양 정보 레이어의 종류 수.

**측정 방법:**
- 좌측 레이어 패널에서 토글 가능한 레이어 수 확인
- 각 레이어가 독립된 데이터 소스 및 시각화 방식을 갖추고 있는지 검증

**현재 구현 현황 (8개 달성 완료):**

| No | 레이어 | 데이터 |
|----|--------|--------|
| 1 | 항만시설 (건물) | Overture Maps 건물 footprint |
| 2 | 해저지형 | 수심 측량 데이터 기반 3D 메시 |
| 3 | 해류 벡터 | 조위 기반 유속/유향 (표층/중층/저층) |
| 4 | 선박 | AIS 데이터 기반 위치/방향/상태 |
| 5 | 항로/정박지 | 항만 운영 구역 |
| 6 | 위험구역 | 수심/조류/통항 기반 경고 구역 |
| 7 | 오염 확산 | 유류 유출 시나리오 시뮬레이션 |
| 8 | 격자 | 좌표 참조 격자 |

---

### 3. 실시간 데이터 갱신 주기 — 목표: 5분 이내

**정의:** 외부 API(조위, 해류, AIS 등)로부터 데이터를 수신한 시점부터 3D 화면에 반영되기까지의 소요시간.

**측정 방법:**
- API 응답 타임스탬프와 화면 갱신 타임스탬프 비교
- 조위(1분 간격), AIS(수초 간격) 등 데이터 종류별 측정
- 네트워크 지연 포함 end-to-end 측정

**달성 근거:**
- 조위 API: 1분 간격 관측 데이터 제공 → 1분 주기 폴링으로 즉시 반영 가능
- AIS: WebSocket 연동 시 수초 이내 반영
- 해류 예측: 1시간 단위 데이터를 5분 간격 보간 표출

---

### 4. 시스템 가용성 (Uptime) — 목표: 99% 이상

**정의:** 월간 서비스 정상 운영 시간의 비율. 계획된 유지보수 시간은 제외.

**측정 방법:**
- 서버 모니터링 도구(PM2, AWS CloudWatch)를 통한 프로세스 상태 추적
- 월간 총 시간 대비 서비스 가용 시간 비율 산출
- 99% = 월간 약 7.3시간 이하의 비계획 중단 허용

**달성 근거:**
- AWS EC2 인스턴스 SLA 99.99%
- PM2 프로세스 관리자의 자동 재시작 기능
- Next.js 프로덕션 빌드의 안정성 (정적 파일 서빙 + API 라우트)
- 별도 DB 의존성 없음 (파일 기반 데이터) → 장애 포인트 최소화

---

### 5. 현장 사용자 만족도 — 목표: 4.0/5.0 이상

**정의:** 인천항 북항 관제 인력을 대상으로 시스템의 실용성, 가시성, 조작 편의성을 평가하는 설문조사 결과.

**측정 방법:**
- 5점 리커트 척도 설문 (1=매우 불만족 ~ 5=매우 만족)
- 평가 항목:
  - 3D 시각화 가시성 (해저 지형, 해류 흐름이 직관적으로 보이는가)
  - 정보 접근성 (필요한 해양 정보를 빠르게 확인할 수 있는가)
  - 조작 편의성 (레이어 전환, 시점 변경이 쉬운가)
  - 위험 상황 인지 (위험구역, 선박 접근 경고가 효과적인가)
  - 기존 시스템 대비 개선도 (2D 지도 대비 공간 파악이 용이한가)
- 관제 인력 5명 이상 대상 평가
- 5개 항목 평균 점수 산출

**달성 근거:**
- 기존 2D 지도 대비 수심별 흐름의 공간적 관계가 직관적으로 파악 가능
- 레이어 토글, 해저지형/해수면 전환 등 현장 맞춤 UI
- 위험구역 진입 시 자동 경고 깜빡임으로 상황 인지 향상
